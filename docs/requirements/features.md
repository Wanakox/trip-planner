# Functional Requirements

This document describes the main functional scope of Trip Planner.

---

## 1. Trip Management

Trip management is the core module of the application. It allows users to create and organize both upcoming and completed trips.

Main features:

- Create trips with name, description, start date, end date, status, budget and main currency.
- Store main travel documentation.
- Add transport information and transport cost.
- Add accommodation information, accommodation cost, location and number of nights.
- Automatically calculate trip duration.
- Automatically calculate the minimum trip cost based on transport and accommodation.
- Compare real expenses against the planned budget.
- Edit existing trips.
- Logically delete trips, allowing optional restoration.
- Mark trips as favorites.
- Associate destinations with each trip, such as countries, cities, places or monuments.
- Save favorite places inside a trip.
- Organize trips by daily planning blocks.

---

## 2. Daily Planning

Daily planning allows users to structure a trip day by day.

Main features:

- Create daily itinerary blocks.
- Add descriptions to each day.
- Add activities or places to visit.
- Organize activities by day.
- Store relevant notes for each day.

---

## 3. Checklist

The checklist module helps users organize tasks before and during a trip.

Main features:

- Create checklists associated with a trip.
- Create tasks inside each checklist.
- Mark tasks as pending or completed.
- Assign priority levels: high, medium or low.
- Reorder tasks when needed.

---

## 4. Expenses

The expenses module manages variable costs generated during the trip.

Main features:

- Register variable expenses such as restaurants, supermarkets, bars or unexpected costs.
- Recalculate the real total cost of a trip.
- Compare the real cost against the planned budget.
- Support expenses in different currencies.
- Convert expenses to the main trip currency when needed.

---

## 5. Completed Trips and Travel Memories

Completed trips can be used as a personal travel record.

Main features:

- Add notes or diary entries to completed trips.
- Rate completed trips.
- Attach photos or files.
- Display trips in list and detail views.
- Represent the trip using a timeline.
- Show visited places on a map.
- Export trip information to PDF.

---

## 6. Search and Filtering

Search and filtering allow users to manage a growing collection of trips.

Main features:

- Search trips by name.
- Filter trips by duration.
- Filter trips by dates.
- Filter trips by budget.
- Filter trips by country or city.
- Filter trips by status.
- Filter favorite trips.

---

## 7. User Management

The user module handles authentication and personal preferences.

Main features:

- User registration.
- User login.
- Profile management.
- Profile picture.
- Language preference.
- Time zone preference.
- Name and personal information management.
- Password recovery.
- Light and dark theme preference.
- Main currency preference.

---

## 8. Future Features

Possible future extensions:

- Integration with Skyscanner or Kiwi for flight search.
- Integration with Google Calendar for travel reminders, flights and check-ins.
- Route generation between visited places.
- More advanced statistics for travel expenses.
- Shared trips between users.
